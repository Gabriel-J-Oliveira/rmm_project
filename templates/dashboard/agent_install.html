Instalação guiada

  1. Selecione o canal e a release assinada.
  2. Copie o comando de instalação e proteja-o como uma credencial.
  3. Execute como administrador no endpoint.
  4. Para o lote AD, o domínio é um filtro informado pelo cliente, não prova de identidade.
  5. Para computadores externos, informe o token manual quando solicitado.
  6. Valide em Endpoints > Detalhe > Agente.
