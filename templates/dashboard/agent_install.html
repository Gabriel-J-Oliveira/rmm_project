Opcional para legado ou lotes controlados. O comando padrão já tenta auto-enrollment sem token em linha de comando.

Instalação guiada

  1. Escolha a URL pública do servidor NightOwl.
  2. Copie o comando PowerShell sem token sensível.
  3. Execute como administrador no endpoint.
  4. No domínio autorizado, a ativação é automática.
  5. Fora do domínio, gere um token manual e cole na janela NightOwl do instalador.
  6. Valide em Endpoints > Detalhe > Agente.

Ambiente: 127.0.0.1 só deve ser usado quando o backend estiver na própria máquina.
Para instalar em outros endpoints, use DNS/IP acessível do servidor NightOwl. Caminho local só funciona na própria máquina; para rede, use UNC ou HTTPS quando disponível.
O modo serviço exige PowerShell como administrador. Para máquinas fora do domínio, use HTTPS com certificado público confiável.
